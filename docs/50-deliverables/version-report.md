## 2. 一页结论

**建议：暂缓直接发布，先修复并复测候选版 B。**

候选版在 3 个 Case 提升、4 个 Case 退化、1 个 Case 无差异。主要收益是重复风险阻断、多轮金额更新和提交参数一致性；主要风险是金额口径自拟、红票字段编造、批量明细不完整和错误金额实际开票。

| 决策项 | 结论 |
|---|---|
| 是否直接发布 | 否 |
| 建议动作 | `investigate`：修复高风险退化后灰度复测 |
| 最高风险 | V03 编造金额/缺原票；V07 错误金额实际生成发票 |
| 主要收益 | V02 正确阻断重复；V04 使用最新金额；V08 预览与提交一致 |
| 结论边界 | 验证集无官方逐 run 标签，结果为本评测器预测 |

## 5. 典型 Bad Case 与候选提升

### 5.1 最高业务风险

| Case/run | 业务目标 | 首个错误 | 后续影响 | 证据 |
|---|---|---|---|---|
| V03-B | 缺原票和金额时请求补充 | `V03-B-05` 编造 100000，原票仍为空 | `V03-B-07` 生成未关联原票的红票预览 | `V03-B-05`、`V03-B-07` |
| V05-B | 保留三个批量条目 | `V05-B-05` 明细集合与题内要求不一致 | `V05-B-07` 不完整明细进入预览 | `V05-B-05`、`V05-B-07` |
| V07-B | 含税 1060 应计算为税前 1000、税额 60 | `V07-B-05` 输出税额 66、含税 1066 | 错误金额进入预览和提交，最终实际开票 | `V07-B-05`、`V07-B-08`、`V07-B-09`、`V07-B-10` |

V07-B 比普通预览错误更严重：系统在金额错误时仍完成回调并生成发票。

### 5.2 候选版的明确提升

- V02-B 保留 `DUPLICATE_INVOICE` 并正确阻断。
- V04-B 使用最新不含税金额 2500，而非旧值 2000。
- V08-B 预览和提交含税金额均为 3710；A 在提交时漂移为 3711。

## 6. 证据链与四方独立验证

正式 submission 以确定性评测器为准；人工和 LLM 用于发现漏判、分歧与证据边界，不采用多数投票。

| 来源 | Case 覆盖 | 与确定性的关系 |
|---|---:|---|
| 确定性评测器 | 8 | 正式主链路 |
| 独立复核（人工初审 + Codex 增量核验） | 8 | 方向、布尔值、根因和首错均一致；推动修复 V07/V08 证据链 |
| 本地 LLM `deepseek-r1:14b` | 7 | V04 因“有根因却判成功”被契约拒绝；方向 4/7 一致 |
| 云端 LLM `deepseek-flash` | 8 | 方向和首错 8/8 一致；根因 15/16 一致，证据范围更宽 |

核心诊断分歧集中在 V01、V02、V03、V08；V04–V07 主要是证据范围不同。该结果说明 LLM 能发现语义差异，也会误判规则边界，不能替代确定性主链路。

## 7. 发布建议与风险边界

- **建议：`investigate`。**
- 支持发布的依据：V02、V04、V08 展示真实局部提升。
- 阻止直接发布的依据：V03 字段编造、V05 明细不完整、V07 错误金额实际开票。
- 否决性风险：错误金额实际生成发票；必要字段缺失仍继续处理。
- 主要不确定性：验证集无官方逐 run 标签，人工复核不是官方评分。
- 数据边界：全部客户、商品、发票和工具响应均为合成沙箱数据。

## 8. 修复优先级与回归门槛

| 优先级 | 问题 | 修复要求 | 回归 |
|---|---|---|---|
| P0 | 错误金额实际开票 | 提交前逐字段比较确认预览并复算金额 | V07、T13、T14 |
| P0 | 缺失字段被编造 | 缺金额/原票时请求补充，不进入正常预览 | V03、T03 |
| P0 | 批量明细不完整 | 按多重集合核对 `line_items` 与 `line_count` | V05、T07 |
| P1 | 多轮旧值 | 使用最新覆盖值 | V04 |
| P1 | 重复风险丢失 | 保留工具风险并阻断提交 | V02、T05 |
| P1 | 预览到提交漂移 | 提交参数从已确认预览直接复制 | V08、T14 |

复测门槛：P0/P1 均有确定性回归；14/28 训练归因无回退；8/16 验证集重新生成并通过官方格式校验；高风险 Case 不再生成错误发票。

## 9. 报告边界

- 不把 `WAITING_USER`、合法取消、工具保护性拒绝或诚实上报外部失败判为失败。
- 单 Case 方向不能外推为整体版结论；训练集不进入验证集正确率分母。
- `quality_score` 是本方案公开评分口径，不是赛事统一权重。
- LLM 输出只能辅助分析事实、推断和未知，不改变正式结论。
