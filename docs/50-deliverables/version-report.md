## 2. 执行摘要

程序预测候选版 B 在 3 个 Case 更好、4 个 Case 更差、1 个 Case 无差异，未出现证据不足。**基线预测处理正确率 5/8，候选版 4/8**；两版预测发票生成率均为 3/8；**候选版平均质量分 82.50，低于基线 86.25**——两轮规则补强识别出「无依据编造金额」与「题内未给口径却自行假定」。候选版仍出现红票字段编造、批量遗漏和金额计算错误。由于验证集没有专家标签，且提升与退化数量相同，不建议直接发布，应先人工复核并修复候选版高风险退化。

## 3. 指标口径与总体结果

所有“正确率”和“生成率”均为评测程序预测。

| 指标 | 口径 / 分母 | 基线 A | 候选 B | 差值 | 说明 |
|---|---|---:|---:|---:|---|
| Agent 处理正确率 | 程序预测正确的 run / 8 | 62.5% | 50.0% | -12.5% | 不得与发票生成率合并 |
| 实际发票生成率 | `invoice_created=true` / 8 | 37.5% | 37.5% | 0 | 不等于正确处理率 |
| 高风险预测数 | `quality_score <= 50` | 1 | 1 | 0 | 仅为本文评分口径 |
| 平均质量分 | 可评分 run 的算术平均 | 86.25 | 82.50 | -3.75 | 分数越高越好 |

## 5. 典型 Bad Case 与证据链

| Case / run | 预测业务目标 | 首个错误事件 | 后续传播 | 工具/外部行为 | 证据事件 | 根因 |
|---|---|---|---|---|---|---|
| V03-B | 缺原票和金额时应请求补充 | `INV-V03-B-05` 编造金额，`original_invoice_id=null` 仍继续 | `V03-B-07` 生成未关联原票的红票预览 | 未调用原票查询，不能归因工具 | `V03-B-05`、`V03-B-07` | `FIELD_FABRICATION` |
| V05-B | 保留 3 个 batch 条目 | `INV-V05-B-05` 只保留 2 项 | `V05-B-07` 预览继续遗漏 | 无工具异常 | `V05-B-05`、`V05-B-07` | `MULTI_ITEM_OMISSION` |
| V07-B | 含税 1060 对应税前 1000、税额 60 | `INV-V07-B-05` 输出税额 66、含税 1066 | `V07-B-07/B-08` 预览和提交继承错误金额 | 服务接受错误参数，未保护阻断 | `V07-B-05`、`V07-B-08` | `AMOUNT_CALCULATION` |

候选提升样例：

- `V02-A` 抹去规则工具返回的 `DUPLICATE_INVOICE`，候选 `V02-B` 正确阻断。
- `V04-A` 使用已被覆盖的旧金额 2000，候选 `V04-B` 使用最新金额 2500。
- `V08-A` 提交含税额从预览的 3710 漂移为 3711，候选 `V08-B` 保持一致。

本验证批未观测到提交阶段的工具保护性拒绝。训练校准样例 `INV-T01-B` 中，`CONFIRMATION_REQUIRED` 被正确识别为工具保护，而不是接口故障；该样例不用于验证集排名。

## 6. 发布建议与风险边界

- **建议：`investigate`。**
- 主要依据：候选版有 3 个预测提升，但**退化 4 个**；**平均质量分低于基线 3.75**；验证集没有专家标签，不能把这些预测直接当成真实准确率。
- 否决性回归：`V03-B` 红票字段编造、`V05-B` 批量遗漏、`V07-B` 金额计算错误。
- 主要不确定性：8 个验证 Case 无官方逐 run 标注；“正确率”和“高风险数”依赖本文规则与评分口径。
- 资源边界：候选版平均耗时增加约 96.6 ms、Token 增加约 28.75，均为模拟数据。
- 复测门槛：三个预测退化 Case 修复并由人工复核；验证集 A/B 全部重新生成；官方格式校验通过；训练集 28 条归因无回退。

## 7. 改进和回归 Case

| 问题 | 建议修复位置 | 应补充的回归 Case | 预期可验证行为 |
|---|---|---|---|
| 缺原票时编造金额 | 红票采集与原票校验 | V03 及缺少原票编号的新组合 | 必须 `WAIT_USER_SUPPLEMENT`，不得生成预览 |
| 批量条目遗漏 | 批量 `line_items` 构造与预览 | V05、T07 及重复/合并条目 | 明细多重集合与数量完整 |
| 含税金额计算偏差 | 金额计算与提交前门禁 | V07、T13 | 税前 + 税额 = 含税，提交前复算一致 |
| 多轮值覆盖 | 采集阶段上下文合并 | V04 | 使用最新轮次金额 |
| 提交参数漂移 | 预览复制到 submit 参数 | V08、T14 | 所有提交字段与确认预览一致 |

## 8. 分界说明

- 本报告基于 8 个 Case 的批量结果，不以任何一个 Case 单独推导整体版本。
- 本文没有使用验证集专家标签，因为官方验证集不提供标签。
- 当前结果只证明评测器可以稳定、可复现地处理这批 Case，不证明真实生产版本的绝对质量。
