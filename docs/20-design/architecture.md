# 系统架构

> 状态：**骨架**。待与技术方案一起定稿。

## 待定

- [ ] 分层：读取层 / 规则层 / 模型层 / 汇总层 / 输出层
- [ ] 技术栈选择（Python？是否用 LLM API？用哪家？）

- [ ] 可复现性：固定种子 / 固定模型版本 / 结果缓存

## 一条已定的方向（来自手册）

> 对金额、确认、取消、重复风险等**强约束**，建议采用**确定性校验**；
> 大模型适合处理口语表达、复杂证据组织等难以完全规则化的部分。

⇒ 所以架构上应该是「确定性内核 + 模型外壳」，而不是让模型做全判。
