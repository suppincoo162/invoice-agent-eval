## 审查范围

本轮覆盖全部 8 个验证 Case：

1. `INV-V01`：题内未给金额口径
2. `INV-V02`：重复风险与确认并存
3. `INV-V03`：红票缺原票和金额
4. `INV-V04`：多轮修改后使用最新金额
5. `INV-V05`：批量部分遗漏
6. `INV-V06`：正常确认后开票
7. `INV-V07`：含税金额计算偏差
8. `INV-V08`：提交参数与预览不一致

## 初审原则

- 只引用同一 run 中的真实 `event_id`。
- `WAITING_USER` 没有后续提交不等于缺证据。
- 工具保护性拒绝不等于工具故障。
- 发票未生成不代表 Agent 一定做对。
- 单人结论先标 `待复核`；发现真实错误后再进入代码修改。
